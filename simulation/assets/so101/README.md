# SO-101 Mesh Assets

These STL meshes are copied from the SO-ARM100 `Simulation/SO101/assets` model set and are used by `../lattice.urdf` for the SO-101 base arm and STS3215 servo visuals.

Source: https://github.com/TheRobotStudio/SO-ARM100

License: Apache License 2.0, matching the upstream SO-ARM100 repository.

Only the SO-101 meshes referenced by `lattice.urdf` are included here. Lattice-specific printed parts are reused from this repository's existing `hardware/` folder instead of duplicated under `simulation/assets`.
